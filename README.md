EMBERLINE — a round-based tactical FPS in three.js. Two teams fight short rounds in the Kestrel Foundry: Vanguard plants the spark charge at Site A (Furnace) or Site B (Crane), Sentinel holds and defuses. Money earned each round buys rifles, SMGs, a marksman rifle, grenades and armor; accuracy beats speed — spread and recoil punish firing on the move. Single-player against bots that push lanes, hold sites, rotate to plants and shoot back.

## Run it

```sh
python3 -m http.server 8080
# open http://localhost:8080/game/index.html in desktop Chrome
```
